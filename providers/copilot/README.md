# GitHub Copilot CLI (`kumikit.provider-copilot`)

Declarative ACP provider for [GitHub Copilot CLI](https://github.com/features/copilot/cli),
using `kumikit.provider-acp` (`copilot --acp`).

## Prerequisites

Install Copilot CLI and sign in:

```sh
copilot login
```

Verify it is on your `PATH`:

```sh
copilot --version
```

## Icon

`icon.svg` uses the GitHub Copilot mark (from `lobehub/lobe-icons`, `githubcopilot.svg`,
tinted neutral slate for light and dark themes) to identify the GitHub Copilot CLI
harness. The mark remains the trademark of GitHub, Inc.
