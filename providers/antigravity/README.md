# Antigravity (`kumikit.provider-antigravity`)

Declarative ACP provider for Google Antigravity CLI (`agy`), using `kumikit.provider-acp`
(`agy acp`).

## Prerequisites

Install Antigravity CLI and sign in:

```sh
agy acp --login
```

Verify it is on your `PATH`:

```sh
agy --version
```

## Icon

`icon.svg` uses Google's Antigravity mark (from `lobehub/lobe-icons`,
`antigravity-color.svg`) to identify the Antigravity CLI harness. The mark remains the
trademark of Google LLC.
