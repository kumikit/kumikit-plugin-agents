# OpenCode (`kumikit.provider-opencode`)

Declarative ACP provider for [OpenCode](https://opencode.ai), using `kumikit.provider-acp`
(`opencode acp`).

## Prerequisites

Install OpenCode and sign in (or configure a provider):

```sh
opencode auth login
```

Verify it is on your `PATH`:

```sh
opencode --version
```

## Icon

`icon.svg` uses OpenCode's mark (from `lobehub/lobe-icons` / `homarr-labs/dashboard-icons`,
`opencode.svg`, tinted neutral grey for light and dark themes) to identify the OpenCode
harness. The mark remains the property of Anomaly / OpenCode.
